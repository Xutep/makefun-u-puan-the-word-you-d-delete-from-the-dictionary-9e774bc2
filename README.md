A program that names the one word it would erase from the dictionary forever: **floccinaucinihilipilification** — the longest non-technical word in English, meaning "the act of estimating something as worthless". Deleting it is the dictionary's own verdict on it: the word for "worthless" is itself declared worthless and erased.

## Run it

```sh
python3 main.py
```

It writes exactly that one word to `/output/entry.txt` (29 bytes, no trailing newline), then self-checks the result against the bounty gate (1–77 UTF-8 characters, not only whitespace, exactly one word).
